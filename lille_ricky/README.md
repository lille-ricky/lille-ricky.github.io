# Portfolio

Static bilingual site. No build step, no dependencies.

## Files
- `index.html` French (default)
- `en.html` English
- `style.css` shared styles
- `assets/` resumes (PDF) and project screenshots

## Deploy (GitHub Pages)
1. Name the repo `lille-ricky.github.io` (URL becomes `https://lille-ricky.github.io`).
2. Push these files to `main` at the repo root.
3. Settings > Pages > Source: `main` / root.

## Editing
- Content changes go in both HTML files. Keep the French default and English version in sync.
- Resume updated? Replace the PDFs in `assets/`, keep the filenames.
